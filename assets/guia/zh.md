# Jayth 指南

本指南介绍已安装版本的 Jayth：每个部分的作用、位置和用法。按钮和菜单的名称与界面中显示的一致（使用本语言）。这台电脑的数据（版本、当前模型、文件夹、快捷键…）会在查询时从应用本身获取，另行附加。

## Jayth 是什么

Jayth 是一款适用于 Windows、macOS 和 Linux 的桌面应用，它把本地 AI 模型（GGUF 格式，借助 llama.cpp 运行）变成在用户电脑上工作的智能体：编写程序、创建和编辑文件、运行命令、使用其他程序、用自己的浏览器上网，以及读取和创建 Word、Excel、PowerPoint 和 PDF 文档。一切都在电脑上完成，模型下载后无需联网即可使用。每个操作都由用户批准（或在自动模式下放手让它执行）。它也可以通过 API 使用模型（OpenAI、Claude、Gemini、Ollama…）。
由 Ing. Jeison Tuiran 开发。自由软件，采用 GPL-3.0 许可证。网站：https://github.com/Json-Tuiran/jayth.ai

## 主窗口

- **侧边栏（左侧）：** 顶部是用于隐藏侧边栏的 ≡ 按钮（Ctrl+Shift+S）和 **Chat / Code** 切换器。下面是 **新对话**（Ctrl+N）、**搜索你的对话**（Ctrl+K）和按日期分组的历史记录（今天、昨天、最近 7 天…；点击分组可将其折叠）。右键点击某个对话：**重命名** 或 **删除**。最底部是你的个人资料按钮（**你的个人资料和设置**），有新版本时还会出现更新按钮。侧边栏隐藏时，把鼠标移到窗口左边缘，它就会滑出来。
- **顶栏：** 左侧是模型状态（例如“● 就绪 · 本地”）。右侧依次是：**临时**（临时聊天）、地球图标（**Jayth 浏览器**）、**面板布局**、文件夹图标（打开工作文件夹）和 **⋯ 更多选项**（重命名对话、打开工作文件夹、删除对话）。在 Jayth Code 中还会出现 **资源管理器**（Ctrl+B）、**终端**（Ctrl+`）和 **智能体面板**（Ctrl+L）按钮。
- **你的个人资料菜单**（在侧边栏底部）：设置、个性化、记忆、助手和技能、计划任务、模型、API 模型…、键盘快捷键、发送反馈…、报告错误…、检查更新、关于 Jayth 和退出。
- **系统托盘：** 显示、快速提问、停止智能体和退出。

## 消息框

- **Enter** 发送；**Shift+Enter** 换行。Ctrl+V 粘贴图像。
- **+** 按钮：附加文件或文档…、附加图片…、附加截图和 **使用助手**。
- **麦克风：** 用语音听写（在电脑上转写；首次使用时会下载听写模型）。
- **权限按钮**（例如“询问”或“自动”）：更改此对话的权限模式。
- **模型按钮**（例如“Qwen3.8 27B · 低”）：切换模型、设置 **推理强度**（回答前思考多少：低、中、高）、下载或添加模型（下载或添加模型…）、管理模型…、API 模型… 和 **引擎**（启动或停止模型）。
- 如果模型已停止，消息框上方会出现带有 **启动模型** 按钮的提示（可以用 × 关闭；情况变化时会再次出现）。如果你在模型停止时输入消息，Jayth 会启动模型，并在模型就绪后发送消息。
- 智能体工作时，发送按钮会变成 **停止**。

## 权限模式

可以在消息框的权限按钮中更改（仅对该对话生效），或在 **设置 › 智能体与权限 › 默认权限** 中更改。共有五种：只读、规划、询问、编辑文件和自动（确切的列表及说明见本版本的数据）。在会询问的模式下，每个操作都会显示 **允许** 和 **拒绝**。敏感操作（删除、安装、`sudo`、改动系统或受保护的路径）始终会请求许可，在自动模式下也是如此。在 **规划** 模式下，智能体会先调研并提出计划；点击 **执行计划** 即可开始执行（或点击 **继续调整**）。要立即停止鼠标控制：把指针移到屏幕左上角。

## 工作时你会看到什么

- 每次操作前，智能体会用一句话说明要做什么。每个操作显示为一行，带有图标，运行时还有动画；点击即可展开详情（确切的命令、更改、结果）。
- **思考：** 展开“思考了…”这一行，可以查看它的推理过程。
- **截图：** 当它通过查看屏幕或窗口来检查某些内容时，截图会显示在聊天中（点击可放大查看）。
- **计划：** 在较长的任务中，消息框上方会固定显示任务列表（计划 · n / m）。
- **提问：** 如果需要某项信息，它会给出选项来提问；点击选项或 **其他回答…** 即可回答。
- 智能体创建或更改的文件可以直接从聊天中打开（路径显示为链接），需要用户运行的命令会带有 **复制** 和 **运行** 按钮。

## 回复上的操作

每条回复下方有 **复制回复**、**朗读**、**重新生成回复** 和 **报告此回复的问题**，右侧显示写出的 token 数和速度。如果回复更改了文件，下方会出现 **更改了 2 个文件** 卡片，列出每个文件、增加和删除的行数以及备注（“新建”“移到回收站”“已移到 …”）：点击即可打开，按钮可将它恢复到这条回复之前的样子；有两个或更多时，还有 **全部撤销**。每个更改文件的操作也有自己的按钮，可以只撤销那一处更改。智能体用过工具时，“工作了 3 min 12 s”这一行会把它做的事和回复分开。

## 工作时：给它写消息、权限和提醒

- **不停止它也能写消息：** 它工作时可以输入并发送（按 Enter，或点 **停止** 旁边出现的发送按钮）。消息会在输入框上方排队（点 × 可移除），智能体在下一步看到它；聊天中会带有备注“在它工作时发送；它在这里读到了”。如果在此之前停止了它，文字会回到输入框。
- **分组的步骤：** 它在操作之间的思考（“思考了片刻”）放在操作组里；完成后，这组操作会折叠成一行，点击即可展开。顶部的状态会显示它已工作多久（“工作中 · 本地 · 1:12”）。
- **权限：** 除了 **允许** 和 **拒绝**，“或者告诉它改做什么，然后按 Enter…”输入框可以拒绝该操作并把指示交给智能体；操作下方会显示“你的要求：“…””。敏感操作和在已连接账户中的操作不会提供“此处始终允许“…””：这些每次都要确认。
- **计划：** 点击 **执行计划** 后，聊天中会显示标记“你批准了计划：正在逐步执行”。
- **控制电脑：** 它使用鼠标和键盘时，屏幕顶部有一个提示，带有 **暂停**（智能体等待，用户可以使用鼠标；之后点 **继续**）和 **停止**。如果智能体要点击提示所在的位置，提示会让开。把指针移到左上角也能停止它。
- **窗口外的提醒：** 如果 Jayth 在后台时它在等待权限或回答，任务栏图标会闪烁并弹出通知；超过 15 秒的任务在用户看别的内容时完成，也会提醒（点击通知会打开那段对话）。

## 对话内存（上下文）

消息框中麦克风旁边的圆环显示对话占用了多少模型内存：空间充足时为强调色，从 70 % 起为琥珀色（并显示百分比），从 85 % 起为红色。到 70 % 时，Jayth 会精简工具的旧输出（保留开头；最后三个保持完整）。如果还不够，到 85 % 时模型会总结较早的部分：用户最后一条消息之前的内容，或在一项很长的任务中它的前几步（最新的几步保持原样）。总结的长度会根据模型的内存调整。点击圆环可以看到占用情况、Jayth 将要做的事、**立即总结** 和 **开始新对话**。总结后留下的提示里有 **查看总结**。在没有显卡的电脑上，总结可能需要几分钟。

## 你的消息上的操作

鼠标悬停在你发送的消息上时：**复制消息**、**编辑并重新发送**（直接在消息中编辑；Ctrl+Enter 发送，Esc 取消）、**从这里重试** 和 **⋯ 更多操作**：**回到这里**（移除该消息及其后的所有内容，并把它的文字放回输入框）和 **从这里开始新对话**（复制截至该处的对话，原对话不变）。如果在该消息之后智能体更改了文件，Jayth 会询问是 **撤销这些更改** 还是 **保留文件**。已被归入超长对话摘要中的消息无法回到。需要等智能体完成（或将其停止）后才能操作。

## 对话

- 对话会自动保存在历史记录中。**搜索你的对话**（Ctrl+K）会搜索标题和消息。
- 标题由模型在第一次回复后自动设置；可用 **重命名** 更改。
- **临时聊天**（顶栏的 **临时** 按钮）：不会保存到历史记录，也不使用或更改记忆。
- 聊天中的错误（例如“无法连接到模型”）会带有 **重试** 和 **移除此提示**。
- 将所有对话导出为 Markdown 或全部删除：**设置 › 数据与隐私**。
- 对话很长时，Jayth 会总结较早的部分，以免模型忘记。

## Jayth Code（项目）

- 点击侧边栏中的 **Code** 进入（Ctrl+2；Ctrl+1 返回 Chat）。**新建项目** 或 **打开文件夹…**。项目显示在侧边栏的 **项目** 部分，每个项目都有自己的对话（右键：**编辑项目…** 可修改名称、文件夹和 **项目指令**；**从列表中移除**）。
- **资源管理器**（Ctrl+B）：按文件类型显示图标；智能体更改过的文件带有绿点。右键：打开、用默认程序打开、新建文件…、新建文件夹…、重命名、复制路径、复制相对路径、移到回收站。按 Ctrl+P 可使用 **转到文件…**。
- **编辑器：** 标签页（Ctrl+S 保存，Ctrl+W 关闭）。Markdown、HTML、SVG 和 CSV 以 **预览** 打开，切换到 **代码** 即可编辑。Word、Excel、PowerPoint 和 PDF 以只读模式显示；图像可缩放查看。**用默认程序打开** 会用系统应用打开文件。长行可开启 **自动换行**（Alt+Z）。
- **自动保存：** 默认在停止输入 1 秒后保存。可在 **设置 › 常规 › Jayth Code 编辑器** 中更改（也可以改为切换标签页或窗口时保存，或者关闭：用 Ctrl+S 保存）。带“●”的标签页有未保存的更改；带“⚠”的表示无法保存（鼠标悬停可查看原因）。
- **终端**（Ctrl+`）：系统自带的终端（Windows 上为 PowerShell，macOS 和 Linux 上为 zsh/bash），位于项目文件夹中；↑ ↓ 可浏览历史命令。适合运行命令，不适合交互式程序。
- **智能体面板**（Ctrl+L）：项目的聊天；智能体在项目文件夹内工作，如果存在 AGENTS.md、JAYTH.md 或 CLAUDE.md，会读取其中的规则。
- **面板布局**（顶栏）：显示或隐藏面板，把智能体放在左侧或右侧，把终端放在编辑器下方或右侧，以及 **专注模式（仅编辑器）**（Ctrl+Shift+M）。分隔条可以拖动；双击分隔条可折叠旁边的面板。所有布局都会被记住。

## Jayth 浏览器

顶栏中的地球按钮。用户可以在其中浏览网页，也可以让智能体使用某个网站（在网站内搜索、填写表单、使用 JavaScript 的页面）。智能体会在你眼前操作它：掌控期间有自己的指针，窗口边缘会发光；用户可以随时介入。密码始终由用户自己输入，智能体在购买、付款、发布或发送个人数据之前都会请求确认。

## 画布

用于用户想查看的网页、长文档、SVG 图表或程序：智能体会把它们显示在聊天旁边的面板中（“在画布中查看”），提供预览和代码、版本（v1 / n）以及保存选项。

## 图像

智能体可以在电脑本地生成新图像（照片、插画、标志、图标、背景、封面）：在你提出要求时，或在任务需要时（为网站、演示文稿或文档配图）。它也可以修改你已有的图像（使用 FLUX.2 [klein]）。生成过程中可以看到当前步骤、剩余时间和预览；完成后图像会在聊天中放大显示，并带有 **打开** 和 **在文件夹中显示**。图像保存在工作文件夹（或项目文件夹）中的“images”文件夹里，或保存在设置中选择的文件夹里。

- 无需联网或外部服务，使用 stable-diffusion.cpp（MIT）和采用自由许可证（Apache-2.0 或 MIT）的图像模型：**FLUX.2 [klein] 4B**（用途广泛，能在图中写字，有显卡时推荐使用）、**Z-Image Turbo**（更逼真，有显卡时效果更好）或 **Segmind Vega RT**（没有显卡时最快，4 步生成，细节较少）。选择“自动”时，Jayth 会根据电脑配置来选择。没有显卡时，FLUX.2 每张图约需 11 分钟（在一台 4 核 i5 笔记本电脑上测得）。
- 首次使用需要安装（约 5 GB，只需一次）：智能体需要时，点击聊天中出现的卡片上的 **安装**（之后点击 **继续**），或在 **设置 › 图像** 中安装。可以查看进度、随时取消，中断后会从断点继续。**移除** 会删除其文件。
- 耗时：有显卡时每张图不到一分钟；没有显卡时需要几分钟（因此没有显卡时以 512 px 生成）。可在“设置 › 图像 › 图像尺寸”中更改。
- 仅当当前文本模型本身不能生成图像时才会使用（目前在 llama.cpp 上运行的模型都不能）。可通过“允许智能体生成图像”关闭。
- 每张图像都是一次写入操作：根据权限模式，生成前需要批准，并且可以撤销。
- 数据图表由智能体用 Python 绘制，示意图则用画布上的 SVG 绘制。

## 知识库

在 **设置 › 知识库** 中选择文件夹（笔记、文档、项目）后，智能体会按语义在其中搜索，而不只是匹配确切的字词（“修车花了多少钱？”能找到那张汽车维修发票的笔记），无需完整读取文件：非常适合对话记忆较小的本地模型。它使用一个在电脑上运行的小型搜索模型（Qwen3-Embedding 0.6B，640 MB，只需下载一次），能理解中文、英文、西班牙文、葡萄牙文等多种语言。支持文本、代码、Markdown、Word、PDF、PowerPoint 和 Excel。

- **语义搜索：** **安装**（只需一次）。
- **知识库文件夹：** **添加文件夹…** 和 **移除**。
- **索引：** 显示包含多少文件和片段以及上次更新的时间；**更新索引**（只重新读取新增或更改的内容）和“打开 Jayth 时更新索引”。
- 智能体只在需要时使用它（例如“根据我的笔记…”），并注明每条信息来自哪个文件。

## 电脑控制和其他程序

智能体可以打开程序和文件，读取任意窗口中的按钮和字段（系统辅助功能），点击、拖动、输入、按快捷键、管理窗口、使用剪贴板，以及对整个屏幕或某个窗口截图。控制期间，屏幕边缘会发光，并显示它的指针。可在 **设置 › 工具 › 允许控制电脑（鼠标、键盘、截图）** 中开启或关闭。在 macOS 上，需要授予 Jayth **录屏与系统录音**（旧版 macOS 中为“屏幕录制”）和 **辅助功能** 权限（系统设置 › 隐私与安全性）。在 Linux 上，它适用于 X11 会话（在 Wayland 上全局控制受限）；列出窗口需要 `wmctrl`。

## 模型

- **模型**（个人资料菜单，或“设置 › 模型 › 管理模型…”）：已安装模型的列表，包括类型、变体和大小。**使用此模型**、**添加模型…**、**定位…**（如果你移动了文件）、**在文件夹中查找…**、**打开文件夹**、**从列表中移除** 和 **删除文件…**。
- **添加模型**（向导）：Hugging Face 上开放模型的目录，并按能否装进你的电脑加以标注（智能体 = 使用工具；视觉 = 理解图像；推理 = 先思考再回答）；也可以手动输入仓库（用户名/Model-GGUF）、使用自己的 .gguf 文件，或选择包含原始模型的文件夹（config.json + .safetensors），由 Jayth 在电脑上将其转换为 GGUF。可以选择量化方式（推荐的会有标记），如果有的话，还可以加上 **视觉**，让模型能看图像和截图。
- **API 模型…**：OpenAI、Claude、Gemini、Ollama、LM Studio 或其他兼容 OpenAI 的服务器。也可以在 **设置 › 模型 › 提供商** 中设置（URL、模型名称和密钥）。
- **启动或停止模型：** 模型按钮 › **引擎**，或提示中的 **启动模型** 按钮。启动后，模型会占用内存并即时响应；停止后会释放内存。
- 下载会显示百分比、速度和剩余时间，中断后可以继续，并用 SHA-256 校验。
- 如果你的某个模型发布了新版本，Jayth 会通知你（可在“设置 › 关于 › 版本更新”中关闭）。

## 引擎与性能

Jayth 会下载适合这台电脑的 llama.cpp 官方版本：搭载 Apple 芯片的 Mac 用 Metal，NVIDIA 用 CUDA，AMD 或 Intel Arc 用 Vulkan，否则用 CPU 版。在 **设置 › 性能** 中有：**更换或更新引擎…**、**启动模型时预热**、**上下文长度（对话记忆）**（默认为 **自动**：使用模型出厂支持的全部上下文，如果所需内存超出电脑容量则相应减少；开启 **压缩上下文** 后可容纳两倍或更多）、**闲置多久后停止模型**，以及 **引擎设置** 中的：CPU 线程数、读取线程数 （自动：没有显卡时使用处理器的全部线程读取）、GPU 层数（自动模式会把模型分配到 GPU 和内存中）、批处理大小、压缩上下文、Flash attention、生成加速、mmap、锁定在内存中和本地端口。引擎设置的更改会在重启模型（**重启模型**）后生效。引擎日志位于 **设置 › 模型日志**。

- **针对这台电脑优化**（设置 › 性能）：不做估算，而是用当前模型实际测试（需要几分钟，期间模型会停止）：用 llama-bench 测试线程数和 flash attention，以及“生成加速”（推测解码：**MTP** 适用于自带这些层的模型，如 Qwen 3.5 和 3.8；**n-gram** 可加快重写代码或文本的速度），然后保留最快的设置。结果会显示在下方（“读取 … tok/s · 生成 … tok/s”）。也可以在引擎设置中手动选择“生成加速”。
- **内存：** 启动模型时，如果电脑内存放不下模型（会非常慢，最好换用更小的变体），或者当时其他程序占用了内存，Jayth 会发出提醒。llama.cpp 为之前的对话保留的内存会自动调整为剩余的空间，以免占用模型所需的内存。

## 个性化与记忆

在 **个性化** 中，你可以告诉智能体怎么称呼你、需要了解你的哪些信息、怎样回答（风格）、用什么语言回答（自动 = 你的消息所用的语言）以及附加说明。**记忆** 会在对话之间保存长期有效的偏好（你告诉智能体时它就会保存，例如“我用 pnpm”）；可以在“个性化 › 记忆”中查看、编辑或删除，也可以关闭。临时聊天不使用记忆。

## 助手和技能

个人资料菜单 › **助手和技能**。**助手** 是带有自己的指令和参考文件的智能体（例如“文稿润色”）；在消息框中通过 **+ › 使用助手** 选择。**技能** 是智能体在适合当前任务时使用的流程（例如“撰写管理层报告并以 Word 文档交付”）；可以在“技能”标签页中创建、导入、启用或停用（**添加示例** 会添加几个示例技能）。

## 计划任务

个人资料菜单 › **计划任务**。任务是智能体在设定时间自动完成的工作（仅一次、每天、周一至周五、每周的选定日期或每隔一段时间），完成后会通知你：**新建任务**、名称、要做什么、何时执行、如何执行（权限）、**立即运行** 和 **查看上次结果**。任务在 Jayth 打开期间运行（包括最小化到托盘时）。也可以直接让智能体帮你安排任务。

## 快捷窗口

一个小输入栏，可以在任何程序中向 Jayth 提问：快捷键 **Ctrl+Alt+J**（可在“设置 › 常规 › 快捷窗口的快捷键”中更改或禁用），或托盘中的 **快速提问**。**附带截图** 会附上一张当时屏幕内容的图像（Ctrl+S）。Enter 发送，Esc 关闭。

## MCP 连接器和网页搜索

- **MCP 连接器**（设置 › 工具）：通过 Model Context Protocol 标准扩展智能体的工具（文件、记忆、Playwright 浏览器、Git、Fetch、GitHub…）。有一些模板可以自动填写表单；连接器可以是电脑上的程序（命令和参数，许多需要 Node.js 或 uv），也可以是远程服务（地址和密钥）。**添加并测试** 会连接它们；如果服务要求登录，会打开其登录页面（之后可在对应的行中点击 **登录** 或 **退出登录**）。
- **账户关联服务**（设置 › 工具）：全部为可选；Jayth 可以在本地离线工作。提供以下服务的卡片：Higgsfield（使用你的积分在云端生成 AI 图像和视频）、Notion、Canva、Gmail、Google Drive、Google Calendar、Linear、Jira 和 Confluence，以及 Hugging Face（无需账户）。**连接** 会在浏览器中打开该服务的页面：用户在那里登录并授权；Jayth 永远看不到密码，并会将授权加密保存在电脑上（自动续期）。**断开连接** 会删除授权。Gmail、Drive 和 Calendar 需要先 **配置 Google…**：在 Google Cloud 中创建一次类型为“桌面应用”的“OAuth 客户端 ID”（启用 MCP 相关的 API，并将你的邮箱添加为测试用户），然后粘贴其 ID 和密钥；三项服务通用。
- 如果任务需要，智能体可以建议连接某个服务：聊天中会出现该服务的卡片，带有 **连接** 按钮，完成后点击 **继续**。任何会更改账户内容的操作（发送、发布、消耗积分）始终需要批准，在自动模式下也是如此；读取则不需要。
- **网页搜索：** 无需任何设置即可使用：默认使用 DuckDuckGo；如果它要求验证，Jayth 不会绕过，而是通过内置浏览器的引擎在后台使用 Bing。Wikipedia 是最后的备选。Brave Search 密钥或你自己的 SearXNG 实例为可选项。

## 界面语言

Jayth 提供西班牙语、英语、葡萄牙语（巴西）、法语、德语、意大利语、日语和简体中文界面。首次运行时使用系统语言（如果不是其中之一，则使用英语）；可在 **设置 › 常规 › 界面语言** 中更改，Jayth 会提示重启以应用更改。智能体回答所用的语言是另一项设置：默认使用用户消息的语言（设置 › 个性化 › 回答语言）。

## 更新

有新版本时，Jayth 会在后台下载（侧边栏按钮显示“正在下载更新… %”），不会打断你正在做的事。下载完成后，按钮会变为 **重启以更新**：点击后，Jayth 会关闭，安装新版本（显示一个“正在更新…”小窗口），然后重新打开。如果不点击，会在关闭 Jayth 时自动安装。打开新版本时会出现一条提示，附有 **版本更新** 的链接。也可以通过个人资料菜单 › **检查更新** 手动检查，并在“设置 › 关于 › 版本更新”中关闭自动下载。更新时会保留对话、设置和模型。

## 所有内容的存储位置

- **设置、对话、引擎和模型：** Windows 为 `%LOCALAPPDATA%\Jayth`，macOS 为 `~/Library/Application Support/Jayth`，Linux 为 `~/.local/share/jayth`（这台电脑上的实际路径见本版本的数据）。
- **Chat 模式的工作文件夹：** 默认为 `文档/Jayth`；可在“设置 › 智能体与权限”中更改。
- **模型文件夹：** 可在“设置 › 模型”中更改。图像模型位于其中的 `imagen` 子文件夹，图像引擎则与 llama.cpp 引擎放在一起（`runtime/imagen`）。
- **便携模式：** 程序旁边如果有 `portable.txt` 文件，所有内容都会保存在旁边的 `userdata/` 中（适用于 U 盘）。
- **隐私：** 所有内容都留在电脑上；Jayth 不会把对话或文件发送到任何服务器。它只在以下情况使用互联网：下载模型和引擎、检查更新，以及用户允许的网页工具（或者使用 API 模型时，该模型会收到那个对话的消息）。
- **卸载：** Windows 上依次打开 设置 › 应用 › Jayth › 卸载；macOS 上把 Jayth 拖到废纸篓；Linux 上删除 AppImage 文件。卸载时不会删除数据和模型。

## 反馈与帮助

个人资料菜单 › **发送反馈…** 或 **报告错误…**（也可以在“设置 › 关于”中找到）：用户在发送前可以检查文本。每条回复下方都有 **报告此回复的问题**。项目地址为 https://github.com/Json-Tuiran/jayth.ai（下载见 Releases）。

## 常见问题

- **“模型已停止”或没有响应：** 点击 **启动模型**（或直接输入消息：Jayth 会自动启动它）。如果无法启动，原因会显示在提示中和“设置 › 模型日志”中；通常是内存不足：请选择更小的量化版本，调低 **上下文长度（对话记忆）**，或使用 **压缩上下文**。
- **速度慢：** 在没有 GPU 的电脑上，大模型会比较慢；可以试试更小的模型、把推理强度降到“低”，如果有 NVIDIA GPU，请检查引擎是否为 CUDA 版（设置 › 性能 › 更换或更新引擎…）。
- **找不到模型（“找不到模型文件…”）：** 点击 **查找**，或在“模型”中点击 **定位…** 或 **在文件夹中查找…**。
- **看不到图像：** 模型需要支持视觉（投影器）；添加模型时请勾选 **包含视觉**。另请检查“设置 › 智能体与权限 › 将截图和图像发送给模型”。
- **无法生成图像或生成失败：** 在“设置 › 图像”中安装生成器，并确认已勾选“允许智能体生成图像”。如果内存不足，请选择更小的尺寸或 FLUX.2 [klein]，并关闭其他程序；最近一次尝试的详情记录在数据文件夹中的 `imagen.log` 日志里。
- **无法使用互联网或鼠标：** 检查“设置 › 工具”（互联网访问、电脑控制和工具列表）。
- **Windows 显示“Windows 已保护你的电脑”：** 安装程序尚未签名：点击 更多信息 › 仍要运行。**macOS：** 首次打开时，右键点按 Jayth › 打开。
- **智能体不允许回到某条消息：** 等它完成或将其停止；已被总结的消息无法回退（请使用新对话）。
- **编辑器标签页显示 ⚠：** 无法保存（文件为只读或文件夹受保护）；鼠标悬停在标签页上可查看原因。
