## Novedades

Arreglos de lo que encontró una prueba larga con Claude dentro de Jayth (146 peticiones, 42.66 USD, solo un 15 % leído
de la caché).

- **Las tareas largas con un modelo por API cuestan mucho menos.** El servicio cobra a una fracción lo que ya leyó, pero
  solo si el principio de la conversación no cambia, y Jayth lo cambiaba casi en cada paso. Ahora:
  - las instrucciones del proyecto y la fecha se fijan al empezar la conversación; si cambian, se avisa al modelo con
    un mensaje en vez de reescribir el principio;
  - con un modelo por API, todas las herramientas van desde el primer mensaje (activar un grupo a mitad de la tarea
    anulaba la caché);
  - las capturas antiguas se retiran de tres en tres, no una en cada paso, y las del último paso siempre llegan;
  - los resultados antiguos se recortan de una vez y con margen, nunca los que el modelo aún no ha visto, y lo
    recortado se guarda entero en un archivo cuya ruta queda en la conversación: el modelo puede volver a leerlo;
  - el indicador de memoria de la conversación dice cuánto lleva gastado y qué parte salió de la caché.
- **Una acción cortada por la longitud máxima ya no se ejecuta a medias.** Si la respuesta del modelo se corta mientras
  escribe un archivo, antes Jayth podía guardarlo incompleto sin avisar. Ahora esa acción no se hace, se avisa en el
  chat y el modelo la repite en partes; si lo cortado era texto, se le pide que siga donde lo dejó. La ayuda de
  «Longitud máxima de cada respuesta» explica cómo se aplica con un modelo por API.
- **Las claves de API, cifradas.** La clave del servidor externo, las de los servicios guardados y la de Brave Search ya
  no se guardan en claro en el archivo de ajustes (ni en sus copias diarias): van cifradas en el equipo, en la misma
  bóveda que los permisos de los servicios conectados. Las que ya tenías se pasan solas al abrir esta versión. Además,
  que el agente lea los ajustes de Jayth, sus copias o la bóveda pide siempre tu permiso.
- **El editor ya no se cierra cuando el agente cambia muchas veces un archivo abierto.** Las recargas se agrupan, los
  archivos muy grandes se abren sin colores (era lo que lo hacía lento), una pestaña con cambios sin guardar pregunta
  sin bloquear la ventana y abrir un archivo ya no marca la pestaña como modificada.

Si vuelves a una versión anterior después de abrir esta, tendrás que escribir de nuevo las claves de API.

**English:** Fixes for what a long test with Claude inside Jayth found. Long tasks with API models cost much less:
project instructions and the date are fixed when the conversation starts (changes are announced in a message), API
models get every tool from the first message, old screenshots are dropped three at a time, old tool results are trimmed
in one go with margin (never unseen ones, and the full text is saved to a file the model can reread), and the memory
indicator shows the conversation's cost and how much came from the cache. An action cut off by the output limit is no
longer run half-done (a file could be saved incomplete); the model redoes it in parts, and cut-off text is continued.
API keys (external server, saved services, Brave Search) are now stored encrypted on the computer instead of in plain
text in the settings file and its daily backups; existing keys move automatically, and the agent reading Jayth's
settings, backups or vault always asks for permission. The code editor no longer crashes when the agent changes an open
file many times. If you go back to an older version after opening this one, you'll need to enter your API keys again.
