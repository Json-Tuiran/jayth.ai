## Novedades

- **El primer mensaje ya no espera detrás del «precalentamiento»:** al encender el modelo, Jayth lee por adelantado las
  instrucciones y herramientas. Si escribías mientras tanto, tu mensaje esperaba varios minutos sin mostrar el
  porcentaje de lectura. Ahora el precalentamiento cede el paso en cuanto envías algo, y además se hace con las
  instrucciones del proyecto que tienes abierto (antes, en un proyecto, no se aprovechaba).
- **Lista de modelos limpia:** el modelo interno de «conocimiento» ya no aparece como modelo de chat; si una versión
  anterior lo añadió, se quita solo de la lista (el archivo no se toca).
- **Los avisos flotantes ya no tapan el cuadro de mensaje** cuando este crece al escribir.
- **`where python` y `which python` funcionan en Windows:** en PowerShell no devolvían nada y el modelo se quedaba sin
  saber dónde está un programa; ahora se usa el buscador de Windows.

**English:** Your first message no longer waits behind the model warm-up (which now yields as soon as you send
something and uses the open project's instructions). The internal knowledge model no longer shows up as a chat model.
Toasts never cover the message box. `where python` / `which python` now work on Windows.
