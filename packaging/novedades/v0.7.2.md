## Novedades

- **Gemma 4 ya no se queda «en blanco» a mitad de una tarea:** cuando el modelo escribía un texto y usaba una
  herramienta en el mismo paso, su plantilla dejaba el historial desordenado y el modelo podía quedarse generando sin
  mostrar nada durante mucho tiempo (o anunciar acciones sin hacerlas). Jayth ahora le envía el historial en el orden
  correcto.
- **Nunca más silencio mientras trabaja:** con un modelo local, el chat muestra cuánto lleva leído («Leyendo tu
  mensaje… 45 % · queda ~2 min») y, si el modelo escribe sin que llegue texto, pensamiento ni acción, lo dice («El modelo
  sigue escribiendo…» con los tokens que lleva). Si no produce nada, Jayth lo interrumpe y le pide que continúe.
- **Menos avisos falsos:** «El modelo anunció una acción sin hacerla» ya no aparece cuando el modelo termina
  preguntándote algo o esperando tu decisión.
- **Herramientas más tolerantes:** si el modelo usa nombres de parámetros de otras herramientas (`old_string`,
  `file_path`, `cmd`…) se aceptan; si falta un dato, el error le dice exactamente cómo llamarla; `pip install` se
  ejecuta con el mismo Python que luego corre el programa; una carpeta vacía se indica como tal; un proceso detenido
  consta como detenido.
- **Sin internet, el modelo lo sabe:** al empezar la tarea Jayth le avisa de que no hay conexión, las herramientas web
  responden «sin conexión» al instante y los comandos que fallan por la red (pip, git…) llevan una pista.
- **Descargas que aguantan los cortes de red:** al perderse la conexión la descarga dice «Sin conexión a internet · se
  reanuda sola al volver», espera lo que haga falta sin gastar reintentos y sigue donde iba. El tiempo restante ya no
  se dispara a cifras absurdas.
- **Tus ajustes, proyectos y modelos a salvo:** Jayth ya no se abre dos veces (el segundo clic trae la ventana que ya
  estaba); cada guardado respeta lo que haya cambiado otra ventana; se guarda una copia diaria de los ajustes; y si un
  proyecto con conversaciones falta en la lista, vuelve solo. «Parar» también corta la respuesta con servidores que
  cierran la conexión.

**English:** Gemma 4 no longer goes silent mid-task: when it wrote text and called a tool in the same step, its chat
template scrambled the history; Jayth now sends it in the right order. With local models the chat shows real reading
progress and says when the model keeps writing with nothing to show, interrupting it if it never produces anything.
Fewer false “announced an action” notices. Tools accept common parameter names from other tools and explain missing
ones; `pip install` uses the same Python that runs the program. When offline, the model is told, web tools fail fast
and downloads wait and resume on their own without absurd time estimates. Jayth now opens only once, merges settings
saved by other windows, keeps a daily settings backup and restores projects that went missing from the list.
