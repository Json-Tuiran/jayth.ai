## Novedades

Arreglos de lo que encontró una prueba larga con Claude dentro de Jayth: herramientas que daban resultados falsos y
comportamientos del agente que confundían al modelo.

### Servicios por API: los errores pasajeros ya no paran la tarea
- **Reintento automático, con cualquier servicio.** Si el servicio está saturado («high demand», «overloaded»), limita
  las peticiones por minuto o tiene un fallo pasajero, Jayth espera y lo vuelve a intentar solo (hasta 4 veces, cada
  vez más tiempo, o lo que pida el propio servicio), y lo dice en el chat. Antes la tarea se paraba con el error.
- **Errores explicados, no en JSON.** Cada servicio los manda a su manera (Gemini, por ejemplo, dentro de una lista);
  ahora se leen todos y se explican en una frase: servicio saturado, límite por minuto, sin saldo, clave rechazada,
  modelo que no existe o conversación que no cabe, con el detalle del servicio debajo, corto.
- **«Ver modelos disponibles» y «Probar»** reintentan con más tiempo si el servicio tarda, y explican igual sus errores.
- **Lo que cada servicio exige de vuelta, se le devuelve.** Algunos adjuntan a sus respuestas datos que piden recibir
  otra vez en el paso siguiente (Gemini, una «firma» en cada acción; OpenRouter, los detalles de su razonamiento).
  Jayth los guarda y se los devuelve tal cual, solo a ese servicio, sin tener que conocer cada uno; antes Gemini
  fallaba con «Function call is missing a thought_signature». Las conversaciones de antes también siguen.

### Resultados que ya no engañan al modelo
- **Buscar en archivos ya mira los grandes.** Antes, un archivo de más de 2 MB se saltaba en silencio y la búsqueda
  decía «sin resultados» aunque el texto estuviera ahí. Ahora se leen por partes, sin tope de tamaño, y si alguno no
  se puede mirar (binarios, documentos enormes, falta de tiempo) el resultado lo dice. Reemplazar en varios archivos
  también llega a los de hasta 20 MB y dice cuáles no tocó.
- **Escribir con el teclado comprueba lo que llegó.** Si el foco se va a otra ventana a mitad, Jayth para (para no
  escribir donde no toca) y le dice al modelo cuántas letras llegaron, adónde se fue el foco y qué falta. Si Windows
  no acepta las pulsaciones, también lo dice; y cuando el campo se puede leer, confirma que contiene lo escrito.
  Para textos largos, el modelo puede pegarlos por el portapapeles (que queda luego como estaba).
- **Los scripts de PowerShell se leen bien en Windows.** Los `.ps1` se guardan con BOM, como necesita Windows
  PowerShell 5.1 para no convertir «ñ» en «Ã±»; un archivo que ya tenía BOM lo conserva, y el modelo puede elegir la
  codificación (UTF-8, UTF-8 con BOM, UTF-16 o ANSI).
- **Las órdenes de PowerShell, legibles y en orden.** Un error de sintaxis (por ejemplo «&&», que Windows PowerShell no
  admite) ya no llega como un bloque de XML ilegible con «En l�nea» y la línea equivocada: llega en una frase clara.
  Los demás errores salen en su sitio entre la salida y con la línea real de la orden, y si hubo errores aunque el
  código final sea 0, se dice.
- **Editar sin cambiar nada ya no dice «Editado».** Si el texto nuevo es igual al que había, el modelo se entera.
- **El detector de bucles ya no bloquea consultas normales.** Volver a mirar la pantalla o la lista de ventanas
  después de hacer algo ya no cuenta como repetición; las acciones bloqueadas no suman, y dos archivos distintos que
  empiezan igual ya no se confunden.
- **Con poca memoria, el modelo ya no recibe una petición vacía.** Si la conversación no cabía, Jayth podía quitarlo
  todo, también tu mensaje en curso, y el modelo solo recibía sus instrucciones. Ahora lo que va desde tu último
  mensaje se conserva siempre.

### El agente y sus ayudantes
- **Reintentar ya no acumula avisos.** Reintentar o editar un mensaje reenvía solo lo que escribiste y tus adjuntos;
  antes arrastraba los avisos que Jayth había añadido («tu turno anterior no terminó», el idioma…) y cada intento
  sumaba otro. Si tu mensaje nuevo llega después de un error, el aviso dice cuál fue el error.
- **Los ayudantes rinden cuentas mejor.** Crear y editar el mismo archivo cuenta como un archivo; si un ayudante con
  permiso para ejecutar comandos cambia archivos con ellos, el agente principal se entera de cuáles (y de que eso no
  se puede deshacer), sobre todo si están fuera de las carpetas que le encargó. La descripción deja claro que las
  carpetas encargadas no limitan los comandos.
- **Los scripts de análisis ven tu proyecto.** `run_python` se ejecuta en la carpeta de trabajo y puede importar sus
  módulos; y el modelo sabe que cada ejecución empieza de cero.
- **Capturas del navegador honestas.** Dicen a qué ancho se maquetó la página y a qué tamaño llega la imagen; si una
  página muy larga no cabe en la captura entera, lo dicen y el modelo puede pedir el resto.
- **Errores de ventanas con pistas.** Si no encuentra una ventana, el modelo recibe la lista de las que hay (y el
  aviso de que el Explorador de Windows 11 junta carpetas en pestañas); un filtro sin resultados en la lista de
  elementos de una ventana ya no es un error.
- **Los documentos que crea el agente no se abren solos:** el chat ya tiene su botón para abrirlos, y el modelo solo
  lo hace si se lo pides.

### Interfaz
- **Barra superior más clara.** Dice con qué trabaja el agente («Listo · Claude», «Trabajando · Qwen3…») en vez de
  «externo» o «local»; si trabaja en otra conversación, dice en cuál («Trabajando en «…»») y un clic lleva a ella. Los
  botones de paneles se ven marcados cuando están abiertos y todos tienen nombre para los lectores de pantalla.
- **El modo de permisos, a la vista.** Cada modo tiene su icono y Automático va en color de aviso; el menú dice qué
  pide y qué no cada modo, y el chat vacío lo explica según el modo elegido (antes decía «cada acción la apruebas tú»
  también en Automático). La primera sugerencia ya no mueve archivos: solo mira.
- **Paneles estrechos.** La barra de cada archivo se adapta al ancho (ya no se corta por los lados), «Ajustar líneas»
  queda en su icono cuando falta sitio, los botones del explorador aparecen al pasar el ratón y, si no cabe el editor,
  el explorador se pliega solo y vuelve cuando hay sitio.
- **Panel del agente.** La miniatura de una captura va justo debajo de su acción; «Pensó durante…» siempre con la
  misma fórmula; con Claude, lo que se ve de su razonamiento se marca como resumen (y se le pide razonar en tu idioma);
  la vista en directo de lo que piensa ya no corta palabras; el modelo dice «· esfuerzo alto»; el indicador de memoria
  enseña siempre el porcentaje; y adjuntar una captura de pantalla deja la ventana como estaba (antes la desmaximizaba).
- **Barra lateral.** Al asomarse flota sobre un velo (un clic fuera la cierra), Code tiene buscador de conversaciones
  y un «+» para empezar otra, y todas las flechas de plegar son iguales.
- **Buscar en Ajustes.** «Buscar ajuste» encuentra cualquier opción por su nombre o su explicación, deja solo las
  páginas que la tienen y la resalta.
- **Aviso por gasto.** En Ajustes › Modelos › «Gasto con modelos por API» puedes pedir un aviso cuando una
  conversación o el día superen una cantidad, y que la tarea espere a que digas si sigue.
- **Editor de código:** sin la raya clara sobre las pestañas.

**English:** Fixes for what a long test with Claude inside Jayth found. Temporary API errors no longer stop the task: with any service, overloaded or rate-limited responses and transient server failures are retried automatically (up to 4 times, with growing waits or what the service asks for), and errors are explained in a sentence instead of raw JSON (overloaded, rate limit, no credit, rejected key, unknown model, doesn't fit), with a short detail; listing models and testing a service retry too. Data a service attaches to its replies and expects back (Gemini's thought signatures, OpenRouter's reasoning details) is now kept and returned to that service only, so Gemini no longer fails with "missing a thought_signature", including in older conversations. File search now reads large files (over 2 MB
they used to be skipped silently, so it said "no results") and reports what it couldn't search; multi-file replace
reaches 20 MB files. Typing checks what arrived, stops if focus moves to another window and says so, and long texts can
be pasted via the clipboard. PowerShell scripts are saved with a BOM so Windows PowerShell 5.1 reads accents correctly,
and PowerShell commands now report syntax errors in a clear sentence instead of unreadable XML, with errors in place,
at the right line, and a note when errors happened despite a final exit code of 0. Edits that change nothing say so,
the loop detector no longer blocks normal checks, and a conversation that doesn't fit in memory no longer sends the
model an empty request. Retrying or editing a message no longer piles up Jayth's notices, and after an error the notice
says what failed. Helpers count each file once and report files changed by their commands (which can't be undone).
run_python can import the project's modules. Browser screenshots state the real image size and when a long page was
cut (and how to get the rest). Window errors list the windows that are open. Documents the agent creates are no longer
opened on its own initiative. Interface: the top bar names the service or model and, when the agent works in another conversation, says which one (click to go there); each permission mode has its own icon (Automatic in a warning color) and the empty chat explains what the mode does; narrow panels adapt (file bar, explorer buttons on hover, explorer folds itself when the editor doesn't fit); screenshot thumbnails sit under their own action; Claude's visible reasoning is marked as a summary; the memory indicator always shows its percentage; attaching a screenshot keeps the window maximized; the sidebar floats over a veil and Code gets a conversation search; Settings has a search box; and you can get an alert (and a pause) when a conversation or the day goes over a spending limit with API models.
