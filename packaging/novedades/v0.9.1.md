## Novedades

Últimos arreglos de la prueba larga con Claude dentro de Jayth: herramientas que faltaban o daban pistas equivocadas, y
un hueco de seguridad.

- **El agente ya no puede pulsar sobre la propia ventana de Jayth.** Por nombre de ventana ya no podía, pero con
  coordenadas (clic, arrastrar, rueda) sí. Ahora, antes de cada acción con el ratón, Jayth mira qué ventana hay en ese
  punto y, si es la suya, no la hace y se lo explica al modelo.
- **Leer páginas web sin espacios metidos en el código.** El código de las páginas salía partido («dt . datetime (»);
  ahora sale tal cual, los bloques de código se conservan con su formato y se quita la publicidad.
- **Herramientas nuevas para el agente:** ver qué comandos siguen en marcha en segundo plano y ver lo que recuerda de
  ti. Además, buscar en la web dentro de un sitio concreto, guardar una captura de pantalla en un archivo y mostrar en el
  lienzo un archivo que ya existe (sin copiar su contenido).
- **Pistas que llevan a algún sitio.** Si el agente intenta leer como documento un archivo que no lo es, se le dice si
  es texto (y que lo lea como tal) o binario (y cómo ver sus bytes); antes se le mandaba a otra herramienta que también
  lo rechazaba. Al reemplazar un nombre en todo el proyecto, se le avisa si es también el nombre de un módulo.
- **La guía de Jayth** que consulta el agente lista las herramientas con su nombre real y el que ves en Ajustes.

**English:** Final fixes from the long test with Claude inside Jayth. The agent can no longer click, drag or scroll on
Jayth's own window by coordinates (it already couldn't by window name). Web pages are read without spaces inserted into
code, code blocks keep their formatting and ads are removed. New agent tools list running background commands and what
it remembers about you; web search can be limited to one site, screenshots can be saved to a file, and the canvas can
show an existing file. Hints now lead somewhere useful (text vs binary files; a replaced name that is also a module), and
the built-in guide lists tools by their real names.
