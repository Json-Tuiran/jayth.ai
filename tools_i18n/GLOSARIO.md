# Glosario de traducción de Jayth

Inglés: de Estados Unidos, tono neutro y directo. Portugués: de **Brasil**, tratando de «você». El español de Jayth tutea:
mantén ese tono cercano.

## Reglas

- Los marcadores se copian **idénticos**: `%s`, `%d`, `%(nombre)s`, `%.1f`, `%%`. Mismo número y mismo orden si no son con
  nombre (si el orden natural cambia, reescribe la frase para respetar el orden).
- Las etiquetas HTML (`<b>`, `<a href=…>`, `<br>`…) y entidades (`&nbsp;`) se conservan; solo se traduce el texto visible.
- Las comillas «» se convierten en “ ” en inglés y portugués. El «…» se conserva.
- No se traducen: Jayth, Jayth Code, llama.cpp, GGUF, Hugging Face, MCP, Ollama, LM Studio, Python, PowerShell, Markdown,
  nombres de teclas y atajos (Ctrl+Alt+J, Esc, Enter, Mayús → «Shift» en en/pt), extensiones y rutas.
- Longitud parecida al original: los textos van en botones y etiquetas con poco sitio.
- Mayúsculas como en el original (solo la primera palabra en mayúscula; en inglés NO uses Title Case en botones/menús
  salvo nombres propios). Ejemplo: «Nueva conversación» → «New conversation».
- Si el español nombra una pieza del sistema, usa su nombre oficial: el Explorador → File Explorer / Explorador de
  Arquivos; el Finder → Finder; la papelera → Recycle Bin (Windows) / Trash (genérico) · Lixeira; la bandeja del sistema →
  system tray · bandeja do sistema; Ajustes del Sistema (macOS) → System Settings · Ajustes do Sistema.
